Tag Definition Example
<h1> </h1> The size of a heading. <h1> is the largest size, going all the way down to <h6> , the smallest size. Anything written within these tags becomes a heading. The title of the website located above the table.
<title> </title> Defines the name of the website if anything is written in between these tags. Located in the tab part of it. The name in the tab.
<p> </p> Created a new paragraph. Anything written between these tags become part of the paragraph. This is a paragraph. A very simple one. You can write as many sentences as you want. So have fun with this. But don't write too many sentences in a paragraph.
<em> </em> Italicizes any word, or words, that are written within these tags. This is a new paragraph. Yes, you can italicize words in a paragraph and in some tags.
<br> If you write this tag after a sentence, you can "break" apart the sentence before that tag from the rest of the paragraph. This sentence is isolated...
From the rest of the paragraph. :(
<strong> </strong> Makes a word, or words, bold. If you, of course, right it in between the tags. This is great if you want to emphasize a word or a sentence. Pay attention. This information is important.
<style> </style> Contents are Internal CSS written in a piece of HTML code to improve its look. The text align of the table header and the alternating colours of the boxes of the table.
<hr> Defines a thematic break. Has a default CSS function built into it. An <hr> tag works like this:
It is a fancier version of the <br> tag.
<a href="..." target="..."> </a> Any word or sentence written between these tags becomes a hyperlink to another website. Within the <a> tag is href and the link of the website you want the person who clicked the word or sentence that's underlined to be redirected to. Occasionally, target may be used within the tag after href to determine if the website will open in the same tab, a different tab or opens a tab each time. CSS may be used to change the font or Ununderline a word or a sentence. This is a hyperlink.
<img src="..." alt="..." style="..."> Opens up an external or internal image in a website. Regardless of which type of image you're trying to open, after img is the following:
(1) src. For an internal image, the image must be in the same folder as the file, and src must point to the correct file and extension, such as .JPG, .JPEG, .PNG, etc. For the external image, src must point to the exact destination of the image, meaning the full link.
(2) alt. This must exist, no matter what type of image you're trying to open. Give it a simple tag such as abc, 123, and so on.
(3) style. This is optional. You can change the height or width of any type of image.
This image can be opened both internally and externally.
<span style="color:..."> </span> Within these tags you can change the color of a word or sentence. Always write style after span. The color is written in the right side in between the quotations. This word is colored.
<iframe> </iframe> Opens a video in YouTube on a website. Rather than manually writing in the <iframe> tag, you can go to any YouTube video, go to share, then embed. Copy the already existing <iframe> tag in the video and paste it in your HTML code.
This YouTube video was opened using the <iframe> tag.
<li> </li> Can be used with an ordered or unordered list. Defines a point or a number in either one of the lists. Allow me to demostrate what <li> is:
  • This is part of the list.
  • This is also part of the list.
  • So is this part.
<ul> </ul> Defines an unordered list. Used with <li>. Anything part of the list is incorporated in point form. This is an example of an unordered list:
  • Write something here.
  • Write something there.
  • Write some more.
<ol> </ol> Defines an ordered list. Used with <li>. Anything part of the list is incorporated in numbered form. This is an example of an ordered list:
  1. Write something here.
  2. Write something there.
  3. Write some more.
<div> </div> Creates a container around the code written within these tags. Some CSS is required to alter some details, such as background color and size. This table is merged with a <div> tag.
