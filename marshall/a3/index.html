Common HTML tags

Tags Definition Examples
<html> used as a container for all of the HTML of an entire document. It tells the browser that the document is an html document. This file is an html file
<head> a container for all the head elements, which can include a title for the document, meta information, styles, scripts, and more. <head> <title> This is a title </title> </head>
<title> creates the title <title> Assignment 1: Tags </title>
<body> defines the document's body, which contains all the contents of an HTML document, including text, tables, images, lists, hyperlinks, and so on. <body> This is content </body>
<p> Starts a new paragraph <p> This is a new paragraph </p>
<h1> - <h6> creates a header (size according to the number after "h". Size ranges from 1 - 6) <h4>

<br> breaks a line and starts a new line This is a sentence. <br>
This is a second sentence.
<a href= "URL"> Creates a hyperlink. default target is current webpage. Use target = "_blank" to open the link in a new tab this is a link: w3school.com
<img src = "URL or file name"> Creates an internal or external image. Internal images are images that are in the same folder as the HTML file. External images are any images from the internet.
